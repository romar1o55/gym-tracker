GYM TRACKER — первая версия

Состав:
- index.html — приложение
- manifest.json и sw.js — поддержка установки как PWA после публикации на HTTPS

Как запустить:
1. Разместить все три файла в одной папке на HTTPS-хостинге.
2. Открыть ссылку в Safari на iPhone.
3. Нажать «Поделиться» → «На экран Домой» → «Добавить».

Данные тренировок хранятся локально в браузере этого устройства (localStorage).
Очистка данных Safari может удалить историю. Синхронизации между устройствами пока нет.
